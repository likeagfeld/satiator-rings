# 🚀 PowerRings Quick Start

## Build in 3 Steps

### Step 1: Make sure Docker is installed
```bash
docker --version
```
If not installed, get it from: https://docs.docker.com/get-docker/

### Step 2: Run the build script
```bash
./quick-build.sh
```

### Step 3: Wait for completion
- First build: ~15-20 minutes
- Subsequent builds: ~2-5 minutes

## Use on Sega Saturn

1. After build completes, copy the `SD/` folder contents to your SD card root
2. Insert SD card into Satiator
3. Power on your Sega Saturn
4. PowerRings will boot with the new Saturn blue theme! 🎮

## What You'll See

- **New Colors**: Sega Saturn blue (#003399) instead of red
- **New Logo**: "PowerRings" branding
- **Same Features**: All original functionality preserved
